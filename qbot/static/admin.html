多模态与回复方式

长回复、代码、链接和表格使用文字；语音准备失败自动回退文字。私聊自动转为 SILK。视觉模型先分析图片，再由聊天模型按人设回复；开启图片理解须选择视觉模型。所有能力默认关闭，使用会产生模型费用。

请在 QQ 开放平台选择相同接入方式。密钥加密保存；启停与编辑不会删除聊天记录。修改前建议等待正在进行的回复完成。

添加供应商

实时通话选择 qwen-audio-3.1-realtime-flash，无需独立 ASR/TTS。实时语音识别用于网页通话，支持 qwen3-asr-flash-realtime；与录音识别分开配置。TTS 可同时供通话及普通语音使用。图片生成当前仅保存配置。ASR 支持 Qwen-Audio-3.x / Fun-ASR-Flash；Filetrans 使用异步任务接口。千问预设会按模型类型填写服务地址和模型。TTS 支持 Qwen Realtime 文本试听；请选择兼容接口，服务地址填 https://dashscope.aliyuncs.com，模型填 qwen3-tts-flash-realtime。机器人聊天仅支持 chat。

OpenAI 兼容接口仅用于 chat，支持按模型能力开启图片输入。填写供应商提供的 HTTPS API 基础地址（通常以 /v1 结尾），不要填写 /chat/completions；不适用于 Responses 或原生语音协议。
